# 📊 Dashboard de Vendas com Streamlit

Um dashboard interativo desenvolvido em Python utilizando a biblioteca **Streamlit** para visualização e análise de dados de vendas.


<a href="https://meudashboarddevendas.streamlit.app/" target="_blank">🚀 Acesse o Dashboard de Vendas</a>

---

## 📌 Sobre o Projeto

Este projeto consiste em uma aplicação web interativa para acompanhamento de métricas e indicadores de vendas. A interface permite visualizar dados consolidados, como receita total, quantidade de vendas e análises temporais e geográficas.

### 🛠️ Funcionalidades
- **Visualização de Indicadores (KPIs):** Métricas de receita e faturamento.
- **Análises Temporais:** Acompanhamento da evolução de vendas ao longo do tempo (mensal/anual).
- **Gráficos Interativos:** Filtros dinâmicos e gráficos para suporte na tomada de decisão.

---

## 🚀 Tecnologias Utilizadas

- **Python 3.11**
- **Streamlit** (para construção da interface de usuário)
- **Pandas** (para manipulação e tratamento de dados)
- **Plotly** (para geração dos gráficos interativos)
